# 受控出库目标点：用方向 + 距离代替坐标

日期：2026-11-08。状态：**待用户评审**。类型：**易用性改进（含持久化结构迁移）**。
版本目标：0.12.0。
关联：[受控出库 spec](2026-10-25-spec-controlled-exit.md)、[v0.11.6 修复](../CHANGELOG.md)。

## 背景

受控出库目前要求用户填两个地图坐标：

| 字段 | 当前值 |
| --- | --- |
| `controlled_exit_x` | 25696 |
| `controlled_exit_y` | 26500 |

用户反馈（2026-11-08，首次真机验收成功后）：

> 设置目标点，可不可以有些一些便利的设置，比如向前 50CM（从 dock），
> 不然坐标点这种 25696 和 26500 对于用户来说，心智负担很重。

这两个数字没有任何直觉含义。用户无法从「26500」判断：机器人会走到哪里、
离危险区多远、改大改小会往哪个方向走。而这三个问题里第一个直接关系安全。

## 实测几何（本屋）

```
充电座                        (25696, 28439)
危险区                        x 24997–26069, y 27123–28764
危险区中心                    (25533, 27943.5)
出库方向                      -Y（实测，2026-10-25 / 2026-11-08 两次）
充电座 → 危险区边界 (-Y)       1316 mm
当前目标点 (25696, 26500)     超出边界 623 mm，即从充电座前进 1939 mm
```

## 关键发现：不能按「最近的边」推方向

充电座到四条边的距离：

| 边 | 距离 |
| --- | --- |
| -X (min_x) | 699 mm |
| +X (max_x) | **373 mm** ← 最近 |
| -Y (min_y) | **1316 mm** ← 最远，但这是真实出库方向 |
| +Y (max_y) | 325 mm ← 最近 |

按「离哪条边最近就往哪走」会推出 **+X 或 +Y**，两者都把机器人推向旁边那扇门 ——
正是 2026-10-25 蹭门事故的方向。用户确认采用**朝危险区中心**的规则：

```
出库方向 = 主轴( 危险区中心 - 充电座 )
```

本屋：向量 (-163, -495.5)，|y| > |x|，取 -Y ✓。
复核：`28439 - 1316 - 623 = 26500`，与现有配置精确吻合。

## 用户故事

- 作为家庭成员，我改出库距离时希望看到「前进 1939mm」这样的说法，而不是 26500。
- 作为家庭成员，我改危险区时希望出库点跟着边界移动，不会突然变成「离边界太近」。
- 作为维护者，我要能手动锁方向，因为区域不规则时自动推算可能偏。
- 作为现有用户，升级后我的行为必须一点不变。

## 功能需求

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| REQ-43 | 用「超出边界距离」表达目标点 | 配置存 `controlled_exit_distance_mm`，不再以坐标为主参数 |
| REQ-44 | 方向自动推算 | 默认 `auto`，取「充电座 → 危险区中心」向量主轴；本屋必须算出 -Y |
| REQ-45 | 方向可手动覆盖 | 可选 north/south/east/west，手动值优先于 auto |
| REQ-46 | 界面同时显示两种口径 | 距离输入框 + 实时反算说明「相当于从充电座前进 N mm」 |
| REQ-47 | 旧配置自动迁移 | 读到 `controlled_exit_x/y` 时反算成距离，行为零变化 |
| REQ-48 | 旧字段保留为只读诊断 | 迁移后 `x`/`y` 仍存在但不再决定行为，作为诊断属性暴露 |
| REQ-49 | 距离必须能真的出区 | 小于「充电座到该方向边界」的距离 → 拒绝保存，报明确原因 |
| REQ-50 | 只能沿主轴走 | x 恒等于充电座 x（或 y，视方向），不支持横向偏移 |
| REQ-51 | 到达容差收紧 | 400mm → 200mm |
| REQ-52 | 不回归既有语义 | 受控出库全部行为、开关默认关闭、失败收尾保持 |

## 界面约束

本项目界面即 HA Options Flow（`config_flow.py` 的 `garage_timing` 步骤），无自定义前端。

- 复用既有 `NumberSelector` / `SelectSelector` 写法，不新建控件类型。
- 复用既有 `field()` / `choice()` 辅助函数与 `timing_suggestions` 预填机制。
- 复用既有草稿暂存（`self.options` + `_garage_values()`），不新建存储。
- 不新增自定义侧栏、面板或 JS。
- 距离与方向字段**只在 `controlled_exit_enabled` 为真时出现**，沿用既有隐藏策略。

## 明确非目标

- 不做地图拖拽选点。
- 不做「朝某个房间/区域走」。
- 不做横向偏移参数。
- 不改危险区编辑器。
- 不改 `suggest_safe_zone`（那是危险区建议，不是出库点）。
- 不为多机器人共享一扇门做仲裁。
