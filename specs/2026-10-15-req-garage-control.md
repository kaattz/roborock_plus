## 用户故事

- 使用不同门硬件的用户能通过选择门和反馈来源接入，无需编写安全判据。
- 清扫的开始、回洗、补电、恢复、最终停靠由同一个控制流程协调。
- 家庭成员可用洗衣机占用等条件阻止自动关门，并能看懂失败原因。
- 已有用户升级不被擅自接管门，原实体身份和自动化引用得到保留。

## 功能需求与验收标准

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| REQ-1 | 集成承载证据与标准流程，按 duid 绑定 | 首版明确支持 V1；同门多机、跨条目重复管理拒绝；Q7/Q10/A01 不假装支持 |
| REQ-2 | 控制目标和开/关证据独立配置 | 覆盖真实位置、双端点、单端点混合、纯计时；关位释放不算开位到达 |
| REQ-3 | 区分确认、估算、未知 | 用户显式接受才允许 estimated 放行；计时不使确认实体变真，不合成百分比 |
| REQ-4 | 持续维护证据有效性 | 所选来源失联、恢复旧值、双端点冲突、相反命令撤销许可，不自动降级；触点稳定不变不因 last_changed 久误判 |
| REQ-5 | HA 受支持移动入口复用互锁 | 清扫、例程按钮、恢复、HA 回充、已知 raw 移动均有前置条件；未知移动不绕过；重复启动不重复下发 |
| REQ-6 | 跟踪本次任务 | 回洗、补电、暂停保留会话；上次结束记录不结束本次任务；外部未知任务使旧会话授权失效，停稳/reset/重启不复活；成功以设备观测为准 |
| REQ-7 | 集成完成标准出入库与收尾 | 开门先于出库；中途停靠不关；本次任务终结且稳定停靠后才关；单一调度无互相开关 |
| REQ-8 | 补齐离库后关门模式 | HA 先开门确认再启动，出库不额外暂停，受信区外才关门；活动会话返航先暂停并确认→门全开→app_resume 原返航；任务关联只授权恢复，初始关联异常也先制动，保持暂停告警；中途回洗/补电停靠保持开，再次离库重复；最终结束稳定停靠后关门。不以命令回执冒充已暂停/恢复 |
| REQ-9 | 家庭策略只提供许可和请求 | 可选许可非 on 不关；不绕互锁；许可恢复重查；核实无任务的 idle 也可请求安全关门 |
| REQ-10 | 处理并发、人工操作与卸载 | 关门等待可被返航/人工/故障抢占；用户暂停不自动恢复；卸载无遗留动作 |
| REQ-11 | 重启不重放危险动作 | 清空计时许可/期限，核对会话再观测；不重放启动/暂停/恢复/关门；无法核对则阻塞 |
| REQ-12 | 故障可见且无危险补偿 | 故障实体、原因与去重事件可消费；超时不关门；服务成功但未启动/未恢复也报告 |
| REQ-13 | 原生配置清楚可校验 | 原生三步 Options Flow：基本/来源、所选反馈、相关时长及交接；未使用字段不占首屏，不猜硬件值；保留旧值、草稿和跨字段校验；双语说明真实/估算与暂停边界 |
| REQ-14 | 兼容迁移与显式交接 | 旧配置不自动开启新流程；多机需绑定；新旧入口共享门所有权；处理旧状态机；保留身份、历史与对照 |
| REQ-15 | 验证不触发设备 | 隔离测试驱动真实实现、轨迹对照、故障回放和变异；保留旧路径对照；实物仅用户操作 |
| REQ-16 | 核心能力随集成交付 | 标准流程不依赖手抄 YAML/本屋实体名；明确 App/厂商定时/物理操作和硬件防夹边界 |

## 使用与失败边界

- confirmed 表示按用户配置的可信来源/到位阈值确认，不保证传感器永不损坏或通路无障碍。
- 本屋 45 秒/95% 是兼容建议，不是所有门标定；开/关行程须分别确认。
- 纯计时不能发现卡门，与物理端点不能宣称有相同保证。
- HA 之外的任务无法命令前拦截；厂商日程由用户自行管理。
- after_exit 目标保留，但首版真实 V1 仅开放 hold_open，能力不足明确拒绝；本次按此边界实施。
- 上一条描述 v0.7.0 已发布范围；2026-10-16 用户随后明确：出库不加暂停，返航必须先确认暂停、等门全开再恢复原返航，覆盖旧自动化直接开门的行为。仍需说明首次返航观测至暂停生效的采样/制动延迟，静态资料和仿真不等于型号硬件验收。
- 异常“不再关门”不等于“门实际开着”，反馈未知直接显示未知。

## 界面约束

- 复用 config_flow.py 的原生 Options Flow、EntitySelector、NumberSelector 和既有地图选项。
- 参考 tests/test_options_ui.py 的轮询/绘图共同可达与翻译完整性约束；可增加门配置步骤，不能丢原选项。
- 仓库无 .agents/rules/frontend-architect.md 和 req/spec/plan 模板；不新增自定义网页、侧栏、标题栏。
- 复用现有危险区编辑器/存储；没有新预览、导出、打印界面，不做平行渲染实现。

## 非目标

- 任意 script/switch 电机动作、多机器人共门仲裁、Q7/Q10/A01 流程适配。
- 绕过固件限制，或把“有 pause 服务”当作“可无损暂停返航”。
- 门口人员/物品识别、替代硬件防夹、拦截物理门及厂商 App。
- 清扫日程、家庭规则引擎、通知渠道，或自动删除用户配置。
- 自动部署、发布、实操，或在验收缺口未关闭时 archive 为全部完成。
